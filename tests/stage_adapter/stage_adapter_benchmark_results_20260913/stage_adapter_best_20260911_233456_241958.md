# Stage Adapter PH/PT/PHT benchmark test 评测结果

## 1. 结论摘要

指定的 Stage Adapter best checkpoint 已在 `dataset/PH/benchmarks`、`dataset/PT/benchmarks` 和 `dataset/PHT/benchmarks` 的全部 `test_*.csv` 上完成评测，共计 **450,756** 条有效测试样本。

三项主任务的 benchmark 宏平均 performance average 再等权平均为 **0.758865**。

- PH 使用 checkpoint 中冻结的 Stage-1 `phla` head。
- PT 使用 checkpoint 中冻结的 Stage-1 `ptcr` head。
- PHT 主结果使用训练后的 Stage Adapter `pht` head；同时补充冻结 `phla`/`ptcr` head 在 PHT 行上的投影结果。
- 主表统一使用固定阈值 `0.5`；验证集选择的 PHT 阈值只作为补充，未使用 test 标签重新选阈值。

## 7. 结果解读与复核

- PH 主任务宏平均 performance average：`0.682006`。
- PT 主任务宏平均 performance average：`0.734833`。
- PHT 主任务宏平均 performance average：`0.859757`。
- PHT head 表现最高的单个 split 是 `PHT/test_unseen_tcr`，performance average 为 `0.976871`。
- `test_unseen_pair` 等小样本 split 的指标方差可能较大，应结合样本数、正负比例和混淆矩阵解读。
- Checkpoint 的 Stage Adapter B round 为 `0`：该 best artifact 对应进入 B 阶段前记录的最优状态，后续 B 阶段未产生更高的 validation selection score。
- 本次只执行推理；没有重新训练、修改 checkpoint，也没有使用测试标签做阈值或模型选择。
- 每个唯一 peptide/HLA/TCR 只编码一次，随后复用 residue-level 表示完成全部行级推理。
